# Tranzelo Movers

Open `index.html`, or serve this directory with `python -m http.server 8080` and visit `http://localhost:8080`.

The supplied project contained compiled React/TanStack bundles for the previous company, but no HTML entry point, source tree, package manifest, build command, or working form service. The rebrand is a dependency-free static page in `index.html`, `styles.css`, and `script.js`. The previous company's unused compiled bundles, fonts, photos, logo, and favicon have been removed after checking current page references. No deployment has been performed.

## Assets and typography

The four supplied Tranzelo photos have AI-enhanced versions for improved exposure, clarity, and noise reduction, saved as `*-enhanced.jpg`. Original JPEGs are retained alongside them. Enhanced images are web-compressed at JPEG quality 90 and below-fold photos are lazy-loaded. The favicon is derived from the full supplied logo. Brand red sampled from the logo is `#e92f30`; buttons use `#c82129` for readable white labels. Manrope is loaded from Google Fonts with local sans-serif fallbacks; an internet connection is needed for the webfont.

## Checks

Run `node --check script.js` and `python validate.py`. No framework build is required. Browser visual checks remain required before publication when a browser is available.

The services strip uses a continuous CSS marquee moving left, with a duplicate group hidden from assistive technology. The animation is disabled for reduced-motion preferences.

## Vercel deployment

The repository is prepared for Vercel as a static site with no dependency installation or build step. `vercel.json` serves the repository root. Import `Hurkify-Team/Tranzelo-Movers` into Vercel with framework **Other**, root directory **./**, and production branch **main**. Once the GitHub integration is connected, pushes to `main` trigger production deployments; other branches create previews. Repository configuration alone does not create the Vercel project or authorize GitHub access.
